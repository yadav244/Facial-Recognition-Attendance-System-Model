# 📖 About

The **Facial Recognition Attendance System** is an AI-powered attendance management application that automates student attendance using Computer Vision and Facial Recognition. Built using **Python**, **OpenCV**, and **MySQL**, the system identifies students in real time and records attendance automatically, eliminating manual attendance processes.

The project was developed to demonstrate how Artificial Intelligence can improve attendance management, particularly in educational institutions and low-resource environments.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yadav244/Facial-Recognition-Attendance-System.git
```

## Navigate

```bash
cd Facial-Recognition-Attendance-System
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Configure MySQL

- Create a MySQL database.
- Update database credentials in the project.
- Import the required tables.

## Run

```bash
python main.py
```
